# 📺 YouTube Beta

A minimalist, responsive YouTube clone built with modern web technologies. This project serves as a practical learning exercise to deepen understanding of frontend development, user interface design, and API integration.

---

## 🚀 Features

* 🔍 **Search Functionality**: Search for videos using the YouTube Data API.
* 📺 **Video Playback**: Watch videos with a clean and responsive player.
* 🧭 **Navigation**: Seamless navigation between search results and video playback.
* 🎨 **Responsive Design**: Optimized for both desktop and mobile devices.

---

## 🛠️ Technologies Used

* **JavaScript**: Core language for application logic.
* **HTML5 & CSS3**: Markup and styling.
* **Vite**: Next-generation frontend tooling for rapid development.
* **YouTube Data API**: Fetches video data and search results.

## 🔧 Installation & Setup

1. **Clone the repository**:

   ```bash
   git clone https://github.com/Jamil-4khtar/youtube-beta.git
   cd youtube-beta
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Run the development server**:

   ```bash
   npm run dev
   ```

4. **Open in browser**:

   Navigate to `http://localhost:5173` to view the application.
